  ЧАСТЬ 1. Схема данных
Вам доступна витрина данных со следующей структурой:

Таблица: patients (пациенты)
 patient_id        UUID, первичный ключ
 birth_date        DATE
 gender            VARCHAR ('М', 'Ж')
 attachment_date   DATE — дата прикрепления к поликлинике
polyclinic_id     INTEGER — ID поликлиники

Таблица: visits (визиты/обращения)
 visit_id          UUID, первичный ключ
 patient_id        UUID, FK → patients
 visit_date        DATE
 visit_type        VARCHAR ('первичный', 'повторный', 'профосмотр','диспансеризация', 'скорая')
 doctor_id         INTEGER
 department        VARCHAR ('терапия', 'хирургия', 'кардиология', ...)

Таблица: diagnoses (диагнозы)
 diagnosis_id      UUID, первичный ключ
 visit_id          UUID, FK → visits
 patient_id        UUID, FK → patients
 diagnosis_date    DATE — дата постановки диагноза
 mkb_code          VARCHAR — код по МКБ-10 (например, 'E40', 'I10')
 is_primary        BOOLEAN — первичный (true) или повторный (false)
diagnosis_type    VARCHAR ('впервые установленный', 'уточненный')

Таблица: dispensary_registry (регистр диспансерного учета)
 registry_id       UUID, первичный ключ
 patient_id        UUID, FK → patients
 mkb_code          VARCHAR — код диагноза
 registration_date DATE — дата постановки на Диспансерный учет
 removal_date      DATE — дата снятия с учета (NULL, если стоит)
 doctor_id         INTEGER


Таблица: examinations (профосмотры)
 exam_id           UUID, первичный ключ
 patient_id        UUID, FK → patients
 exam_date         DATE
 exam_type         VARCHAR ('предварительный', 'периодический', 'углубленный')
result            VARCHAR ('годен', 'ограниченно годен', 'не годен')


Важные нюансы:
- В таблице `diagnoses` поле `is_primary = true` означает, что диагноз поставлен впервые в жизни пациента  (не в рамках визита).
- Один пациент может иметь несколько записей в `dispensary_registry` по разным диагнозам.
- В таблице `visits` поле `visit_type = 'профосмотр'` — это отдельный тип визита, не связанный напрямую с таблицей `examinations`
- "Учитываем только пациентов, которые стоят на Д-учёте сейчас (removal_date IS NULL)"
