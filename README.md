# SQL Test Assignment — Hospital Analytics

Тестовое задание на разработку SQL-запросов для аналитической витрины медицинской организации.

## Среда разработки

- DBMS: PostgreSQL
- Original task: ClickHouse SQL
- Test data: локальная синтетическая БД

> На момент выполнения у меня не было доступа к ClickHouse,
> поэтому запросы были разработаны и проверены в PostgreSQL.
> Логика решения соответствует постановке задачи,
> однако отдельные конструкции SQL могут отличаться синтаксически.

## Основная задача

Необходимо посчитать количество пациентов, у которых:

1. в январе–марте 2026 года впервые установлен диагноз из группы E40–E46;
2. пациент находится на диспансерном учёте;
3. постановка на диспансерный учёт выполнена по тому же диагнозу;
4. до постановки на учёт был профосмотр;
5. между профосмотром и постановкой на Д-учёт прошло не более 45 дней.

## Подход

Решение строилось в два этапа:

1. Сначала реализован базовый запрос для проверки бизнес-логики.
2. После проверки результата запрос был переработан с предварительной фильтрацией данных и уменьшением объёма данных, участвующих в `JOIN`.
